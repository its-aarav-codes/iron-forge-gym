# 🏋️ Iron Forge Gym — Responsive Gym Website

Link: https://its-aarav-codes.github.io/iron-forge-gym/

A modern, mobile-first gym website built to showcase a professional fitness brand with a bold and clean visual identity.

---

## 🚀 Project Overview

Iron Forge Gym is a responsive single-page website designed for a premium fitness center.  
The project focuses on strong typography, clear layout, and conversion-oriented sections such as programs, pricing, and contact.

This project is part of my web development portfolio and demonstrates real-world frontend development skills.

---

## ✨ Features

- Fully responsive design (mobile, tablet, desktop)
- Clean and bold gym-themed UI
- Smooth scrolling navigation
- Clear call-to-action sections
- Optimized layout for fast loading

---

## 🛠️ Tech Stack

- HTML5 — semantic structure

- JavaScript (Vanilla) — basic interactivity  
- GitHub Pages — deployment
